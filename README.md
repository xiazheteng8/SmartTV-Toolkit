## 📺 项目介绍

TV Studio 是一款面向 Android TV 及相关 Android 设备的 Windows 桌面管理软件。

项目由原有的电视自动化精简工具升级而来，采用全新的图形化 UI，将 ADB 设备连接、Scrcpy 投屏、遥控器、文件管理、APK 安装、第三方桌面管理、系统应用精简以及 AI 智能分析整合到一个工作区中。

TV Studio 不只是电视精简工具，也希望成为日常管理 Android TV 设备的一站式工作台。

- 当前平台：Windows
- 后续计划：扩展至 macOS
- 设备连接：ADB 有线、无线及配对码连接

## ✨ 功能介绍

### 1. 设备连接管理

提供多种连接方式，适配不同 Android 版本和设备环境：

- ADB 无线连接
- ADB 有线连接
- 高版本 Android 配对码连接
- 设备连接状态显示
- 连接历史记录

### 2. Scrcpy 设备工作区

基于开源项目 [Scrcpy](https://github.com/Genymobile/scrcpy) 提供设备投屏与控制能力。

在电脑上查看和操作已连接的电视或 Android 设备：

- **实时投屏：** 在电脑上查看设备画面。
- **独立窗口：** 支持将投屏画面分离，方便观察和操作。
- **截屏：** 保存当前设备画面。
- **录屏：** 录制设备画面并保存为视频文件。
- **APK 安装：** 支持通过拖拽 APK 文件进行安装。
- **文件传输：** 支持拖拽普通文件传输至设备下载目录。
- **文件管理：** 对设备文件进行管理。

支持触屏的设备还可以进行手势操作。

### 3. 电视遥控器

通过软件界面控制已连接设备，支持：

- 首页
- 返回
- 菜单
- 上、下、左、右方向键
- 确认
- 音量控制

### 4. 应用扫描与识别

提供快速扫描和深度扫描两种模式。

**快速扫描**

- 设备连接成功后自动执行。
- 快速获取设备应用列表。

**深度扫描**

- 进一步解析应用名称。
- 优先显示中文应用名称。
- 支持取消后续扫描任务。

首次使用建议执行深度扫描，以便更直观地识别设备中的应用。深度扫描可能需要一定时间。

### 5. 第三方桌面管理

支持安装第三方电视桌面，并新增 Aerial 桌面：

- 提供多个第三方桌面选择。
- 根据设备架构和系统版本获取适配的 Aerial 版本。
- 安装后可在设备上尝试设置默认桌面。

部分电视系统可能限制第三方桌面的默认设置，实际效果以设备支持情况为准。

### 6. 电视应用精简

保留原有精简流程，并优化应用分类和操作方式。

提供两种精简列表：

- 普通精简列表
- 深度精简列表

支持的操作：

- 一键选择
- 一键停用
- 一键卸载
- APK 备份

新增 AI 分析分类：

- 推荐卸载
- 谨慎卸载
- 系统组件

应用分类依赖关键词匹配或 AI 分析结果，不同品牌、型号及系统版本的应用情况可能不同。执行操作前请自行核对应用用途。

### 7. AI 智能分析

TV Studio 提供三种 AI 接入方式，辅助分析设备应用并生成分类配置。

**方式一：API 对接**

填写相应 API 参数，连接支持的 AI 服务。

**方式二：本地 AI Agent**

对接本地 AI Agent，由本地 Agent 参与自动化分析处理。

**方式三：AI 对话模式**

适合不方便配置 API 或本地 Agent 的用户。

使用流程：

1. 在软件中导出应用分析文件。
2. 将文件发送给 GPT、豆包等 AI 助手。
3. 根据应用信息完成分析。
4. 将 AI 返回的配置文件导入 TV Studio。
5. 生成对应的应用分类列表。

AI 输出仅供辅助判断，不能保证分类完全准确。请勿未经检查就批量卸载应用。

### 8. 纠错与恢复入口

软件提供部分纠错辅助功能：

- 尝试撤销最后一次精简。
- 尝试恢复已删除的应用。
- 提供进入恢复出厂设置的入口。

这些功能不保证能够恢复所有应用或解决所有设备故障，具体取决于设备、系统版本和操作情况。

## 🚀 使用教程

### 第一步：开启电视开发者选项

不同品牌和系统版本的设置路径可能不同。常见方式：

1. 打开电视设置。
2. 进入「关于」页面。
3. 找到「产品型号」或「系统版本」。
4. 连续点击约 5 次，部分设备可能需要点击 7 次。
5. 返回设置页面，找到开发者选项。

### 第二步：开启 ADB 调试

根据电视系统的设置入口：

- 开启 ADB 调试。
- 开启安装未知来源应用权限（如后续操作需要）。

具体菜单名称和位置以电视品牌及系统版本为准。

### 第三步：获取设备 IP 地址

在电视网络设置中查看当前网络 IP 地址。

无线连接时，确保电脑与电视处于可以相互访问的网络环境。

### 第四步：连接设备

打开 TV Studio，根据设备情况选择：

- 有线连接
- 无线连接
- 配对码连接

连接成功后，软件会显示设备连接状态。

### 第五步：开始管理电视

连接成功后，可以使用投屏、遥控器、文件管理、APK 安装等基础功能，也可以进入精简向导完成应用扫描、桌面安装、应用分类和精简操作。

## 🛠 电视精简四部曲

### 第一步：深度扫描

扫描设备应用并解析应用名称。

建议首次使用执行深度扫描，便于识别应用。

### 第二步：我的桌面我说了算

选择并安装第三方桌面，包括新增的 Aerial 桌面。

请先在电视上验证第三方桌面能够正常启动，再考虑处理原厂桌面。

### 第三步：AI 分类卸载

根据普通精简列表、深度精简列表或 AI 生成的分类建议，检查应用后选择停用或卸载。

建议优先停用并观察设备运行情况。不要仅凭应用名称或 AI 建议判断系统组件是否可以删除。

### 第四步：再见了原厂

卸载电视自带桌面属于可选的高风险操作。

请确认第三方桌面能够正常启动，并了解设备是否允许卸载原厂桌面。

部分设备可能禁止卸载，或在重启后自动恢复原厂桌面。

### 搞错了？重来！

出现问题时，可以尝试：

- 撤销最后一次精简。
- 尝试恢复已删除应用。
- 通过电视 Recovery 恢复模式进行初始化。

上述恢复功能不保证有效，也不能替代设备自身的恢复机制。

## ⚠️ 风险提示

> **电视系统精简存在风险。请在充分了解设备恢复方法后再使用相关功能。**

不同品牌、型号、硬件架构和 Android 系统版本之间存在差异。

操作不当可能导致：

- 电视黑屏。
- 开机卡在 LOGO。
- 无法进入系统桌面。
- 系统组件异常。
- 设备无法正常使用。

使用前请务必：

1. 自行搜索并了解对应品牌电视的 ADB 连接配置。
2. 查明通过遥控器或电视实体按键进入 Recovery 恢复模式的方法。
3. 至少提前实际测试一次，确认能够成功进入恢复模式。
4. 了解设备初始化及恢复出厂设置的操作方法。
5. 仔细检查应用列表，不要随意卸载不认识的系统组件。
6. 在卸载原厂桌面前，先确认第三方桌面能够正常启动。

**AI 分类、自动分类和恢复功能均不能保证结果完全准确或一定有效。**

使用本工具前，请自行评估风险。因设备差异、误操作、系统限制或其他原因造成的问题及后果，由使用者自行承担。
