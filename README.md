# 瞎折腾 TV 助手 3.0.1

Windows、macOS Apple 芯片版和 Intel 版的产品版本统一为 3.0.1。版本整理不迁移数据目录，也不限制从此前较高版本号覆盖安装。运行时和第三方 APK 保留各自真实版本。

## 两端同步功能

- API 分析：自主配置优先；个人 Key 优先，公共免费路由受额度限制。
- 连接本地 AI Agent：自动检查常见本机端口的兼容模型接口，显示相关进程；确认后读取完整扫描上下文，分批给出建议。进程存在不表示可接入。无兼容接口时使用文件交接，不读取其他应用凭据。
- AI 对话分析：一键导出完整清单、分析要求、设备标识和扫描指纹；上传或粘贴给聊天型 AI，导入完整 JSON 后自动刷新三类结果。拒绝错误设备、过期指纹及清单外包名；缺失意见明确标注，不继承旧建议。
- 展示推荐卸载、谨慎卸载、疑似系统组件及 AI 意见。只有 AI 的“疑似系统组件”显示红色；本地分类只有“系统组件”显示红色。预装身份本身不触发红色。
- 高风险入口单独解锁，需输入风险确认语和目标电视标识，再次确认后只尝试当前用户卸载。不自动获取 root、不永久删除系统分区；桌面仍需专门验证。系统卸载可能导致黑屏、断网或需要恢复出厂，恢复不作保证。
- 保留无线配对、最近连接、操作批次撤销、任务进度及安全边界取消、投屏独立窗口、拖入 APK、文件管理、截屏和录屏等功能。

## AI 对话文件流程

扫描电视 → 选择精简方式 → AI 对话分析 → 一键导出分析任务 → 将文件上传/粘贴给聊天型 AI → 获取符合任务要求的 JSON → 导入并刷新 AI 意见。

保留 device 和 scan_hash 原值。软件不会自动读取聊天网页；导入只更新建议，不发出卸载命令，不自动勾选卸载项。文件包含应用名称、路径等信息，上传前请自行确认。

## 验证与限制

Windows：72 项业务/模拟设备检查、32 项界面检查及 24 项安装器检查通过。

Mac 业务代码：27 项业务检查、26 项 Electron 界面模拟检查通过，覆盖三种分析入口、文件交接、系统保护、临时权限范围、撤销与统一版本号。Mac 界面测试运行在 Windows 测试运行时，不等于 Mac 真机执行。

两种 Mac 包检查架构、代码页散列和资源散列，并保留 Unix 执行权限及框架相对符号链接。采用 ad-hoc 本地签名，没有 Apple Developer ID 签名和公证。当前没有 Mac 主机与电视，Mac 启动、安装及电视连接/卸载/恢复仍需真机验收；真实 Agent 的接口也需在对应环境确认，当前环境曾限制回环套接字访问。

首次打开 Mac 候选版本如遇安全提示，请按 Apple 官方说明核实来源并处理：https://support.apple.com/zh-cn/102445 。无需关闭系统安全检查。若报告损坏、签名无效或无法运行，请保留提示反馈，不应直接视为普通首次打开提示。

用户数据与备份位置保持不变。覆盖安装保留旧版备份。源码分别提供 Windows 和 macOS 包；Mac 源码需要 Node.js 22.12+，npm ci 后运行测试与构建脚本，构建过程与平台限制见 scripts 目录。

## 本地分类规则

普通卸载：广告、推广、购物及部分统计组件等候选。深度卸载：录音、图库、浏览器、播放器等有用但可选应用。重点审查：音频、遥控、红外、Wi-Fi、蓝牙、输入法、HDMI、DRM、投屏等，可能影响重要功能。系统组件：开关机、设置、ADB、基础系统服务等，仅此类标红。未知包默认重点审查。

两端共享同一份规则，按包名和功能判断。品牌和固件差异无法仅靠包名完全确认；分类是审查建议，不是全品牌安全认证。预装或位于系统分区不等于核心组件，分类也不会绕过实际保护与卸载确认。
