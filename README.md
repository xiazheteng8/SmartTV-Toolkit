# TV Studio｜瞎折腾 TV 助手

面向 Android TV 和 Google TV 的桌面管理工具，支持 **Windows、macOS Apple 芯片和 macOS Intel 芯片**。可以在电脑上投屏、遥控、安装 APK、管理文件，也可以扫描应用并按需精简。

## 下载与安装

到 [GitHub Releases](https://github.com/xiazheteng8/TV-Studio/releases) 找到 **3.2.0**，展开 **Assets**，按电脑平台下载对应安装包。

| 平台 | 安装包 |
| --- | --- |
| Windows | `TVStudio-3.2.0-Windows-Setup.exe` |
| macOS · Apple 芯片 | `TVStudio-3.2.0-macOS-AppleSilicon.zip` |
| macOS · Intel 芯片 | `TVStudio-3.2.0-macOS-Intel.zip` |
| 源码 | `TVStudio-3.2.0-Source.zip` |

Windows 下载后运行安装程序。macOS 解压后打开 TV Studio。首次使用先在电视上开启 ADB 调试，连接时留意电视端的授权提示。

## 3.2.0 更新

- **新增 macOS 客户端**，分别提供 Apple 芯片和 Intel 芯片安装包。
- **修复 Windows 自动分类**，补强系统保护，避免部分系统组件被误归为「深度精简」。
- **新增常用软件安装**，按图标卡片展示应用，可单独安装。内置盒子伴侣、小白文件管理器、Aptoide TV、Emotn Store、FlClash 和 Hiddify 等应用。
- **新增接口配置推荐**，安装页可复制「我的电视零 / 影视仓」的点播和直播地址，也可用浏览器打开「更多配置」。接口来自网络收集，可用性以实际测试为准。

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| ADB 连接 | 支持有线、无线 IP 和无线调试配对码，保留连接记录 |
| 投屏与遥控 | 使用 [scrcpy](https://github.com/Genymobile/scrcpy) 投屏，支持独立窗口、截屏、录屏及方向键、返回、音量等遥控操作 |
| APK 与文件 | 导入或拖入 APK，识别应用名称和包名，浏览设备文件 |
| 应用扫描与精简 | 快速扫描获取应用清单，深度扫描补全名称，支持停用、卸载和备份 APK |
| 桌面管理 | 安装第三方桌面，支持 Aerial 桌面适配，可备份原厂桌面 APK |
| AI 辅助分析 | 支持 API、本地 AI Agent 和 AI 对话文件。可导出分析任务，获取建议后再导回 TV Studio |

## 连接教程

1. **打开开发者选项。** 在电视的「设置 → 关于」里找到系统版本、版本号或产品型号，连续点击，直到出现开发者模式提示。菜单名称和点击次数因设备而异。
2. **开启调试。** 回到设置，打开 ADB 调试或无线调试。连接时请在电视端确认电脑的调试授权。
3. **选一种连接方式。** 有线连接可在 TV Studio 中选择已识别设备。无线连接时，让电视和电脑处在能互相访问的网络中，再输入电视的 IP 和连接端口。使用配对码时，先按电视显示的信息配对，再使用无线调试页面上的**连接端口**连接。
4. **开始操作。** 确认设备显示已连接，即可投屏、遥控、截屏、录屏或浏览文件。只想装应用，可以直接打开「常用软件安装」。

## 电视精简四步走

| 步骤 | 操作 |
| --- | --- |
| 1. 扫描应用 | 快速扫描获取应用列表。包名看不懂时，运行深度扫描补全应用名称。两次扫描更新同一份列表。 |
| 2. 选装第三方桌面 | 想换桌面可安装 Aerial 或其他桌面。先确认它已设为默认，并在电视上测试主页键。 |
| 3. 复核后精简 | 按「普通精简」或「深度精简」筛选，也可参考 AI 分析。逐项核对用途，优先少量停用并观察，确认无影响后再决定是否卸载。 |
| 4. 按需处理原厂桌面 | 原厂桌面页可备份 APK、卸载或跳过。卸载前需确认另一套可用桌面已设为默认，部分设备会限制此操作。 |

扫描、分析和精简任务运行时，仍可使用配对、投屏、截屏、录屏和文件浏览等功能。切换设备前会先结束旧设备上的扫描或分析，已经提交的停用或卸载会在原设备上完成。

### AI 对话文件怎么用

打开「AI 对话分析」，导出任务 JSON，把文件交给 AI 助手。请它按任务格式返回 JSON，再把结果导回 TV Studio，在列表里逐项复核。也可在软件内使用 API 或本地 AI Agent。

任务文件可能包含设备地址、包名和应用列表。发送给外部 AI 前，请先检查文件内容。

### 精简后遇到问题

如果设备仍能连接 ADB，先到恢复入口尝试撤销最近一次精简，或选择需要恢复的应用。能否恢复取决于设备和应用状态，APK 备份不包含应用数据。若电视已经无法进入桌面或连接 ADB，请按对应品牌和型号的官方说明使用 Recovery。恢复出厂设置会清除设备上的数据和设置，应作为最后手段。

## 精简前先看

> **自动扫描和 AI 建议仅供参考。** 不同品牌、型号和固件的系统依赖可能不同。系统精简操作不当可能导致功能异常、黑屏或无法进入桌面，请自行复核卸载列表。

- 系统底层、设置、输入法、USB、HDMI、Wi-Fi、遥控、开机引导和恢复组件等应保留。被 TV Studio 识别为受保护的组件会拦截停用和卸载。
- 对用途不确定的应用，先少量停用并观察。精简前备份重要数据，确认能重新连接 ADB，并了解设备的恢复方式。APK 备份只保存安装包。
- 如需同时精简和装软件，请先完成精简，再执行安装操作。
